# Change History Template: Go

Covers: `.go`, `go.mod`

Place at the end of the file. The block is a `//` comment, which `gofmt` and `go mod tidy` keep.

```go
// --- Change History -------------------------------------------------------
// | PR     | Summary                                                       |
// |--------|---------------------------------------------------------------|
// | #N     | one-line description                                          |
```
