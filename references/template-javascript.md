# Change History Template: JavaScript and TypeScript

Covers: `.js`, `.mjs`, `.cjs`, `.jsx`, `.ts`, `.tsx`

Place at the end of the file. The block is a `//` comment.

```javascript
// --- Change History -------------------------------------------------------
// | PR     | Summary                                                       |
// |--------|---------------------------------------------------------------|
// | #N     | one-line description                                          |
```
